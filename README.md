# DevSpace — Developer Social Media

A developer social media platform where every profile page is uniquely generated by [Codex](https://platform.openai.com/docs/guides/codex). Built for the Codex Hackathon.

[![CI](https://github.com/OpenAI-Demo-Team/ecom/actions/workflows/ci.yml/badge.svg)](https://github.com/OpenAI-Demo-Team/ecom/actions/workflows/ci.yml)

## What Makes It Special

- **Vibe-Coded Profiles**: Describe your aesthetic, and Codex generates a completely custom HTML/CSS profile page. Cyberpunk terminals, pink minimalism, cosmic starfields — every developer's page is unique.
- **Social Feed**: Posts, likes, comments, friend suggestions — a real social media experience.
- **Self-Healing Loop**: Codex monitors API health, files incidents, proposes fixes, and opens remediation PRs via the Responses API (optional auto-merge).
- **Codex PR Drafts**: After vibe-coding, users can generate a GitHub-ready PR draft (and optionally auto-open a PR).
- **Data Persistence**: All user data, posts, profiles, and metrics persist across sessions.

## Tech Stack

- **Frontend**: Next.js 14 (App Router), React 18, TypeScript
- **Backend**: Next.js API Routes
- **AI**: OpenAI Node SDK + Codex Responses API (with deterministic fallbacks)
- **Storage**: JSON file persistence
- **Testing**: Vitest

## Quick Start

```bash
npm install
npm run dev    # http://localhost:3000
```

Recommended Node version: `20.x` (`.nvmrc` included).

For Codex-powered generation (instead of fallback themes), create `.env.local` in the project root:

```bash
OPENAI_API_KEY=your-openai-api-key
CODEX_MODEL=gpt-5.3-codex
```

Run quality checks before opening PRs:

```bash
npm run check
```

## Project Structure

```
app/                  # Next.js pages
  feed/               # Social feed
  profile/[username]/ # Full-page profile takeover
  admin/              # Latency monitoring + self-healing
  api/                # API routes
src/backend/
  db/store.ts         # JSON persistence + seed data
  auth/session.ts     # Cookie-based auth
  services/           # Business logic
    postService.ts    # Posts, likes, comments
    friendService.ts  # Friend connections
    profileGenerator.ts # Codex profile generation
    githubIncidentService.ts # Jira/GitHub incident remediation integrations
    jiraService.ts    # Jira issue + workflow transitions
    codexSdkClient.ts # OpenAI Codex SDK integration
tests/                # Vitest test suites
```

## Environment Variables

```
OPENAI_API_KEY=your-openai-api-key      # Required for live Codex generation
CODEX_MODEL=gpt-5.3-codex  # Codex-only model (higher quality default)
CODEX_REASONING_EFFORT=medium # low|medium|high (higher = richer output, slower)
CODEX_TIMEOUT_MS=45000     # Optional: increase when large profile generations time out
CODEX_MAX_OUTPUT_TOKENS=3200 # Optional: increase for complex profile output completeness
DEVSPACE_DEFAULT_GITHUB_TOKEN=your-github-token   # Optional: hidden signup prefill for demo PR creation
GITHUB_REPO_OWNER=your-org-or-user      # Optional: enable auto PR creation
GITHUB_REPO_NAME=your-repo              # Optional: enable auto PR creation
GITHUB_BASE_BRANCH=main                 # Optional
INCIDENT_AUTO_MERGE=false               # Optional: set true only if you want auto-merge in incident demo
```
