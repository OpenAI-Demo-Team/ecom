# DevSpace Demo Script (5 minutes)

## Setup Checklist (do this before presenting)

1. Install dependencies and start fresh data:
```bash
npm install
```

2. Optional but recommended for live Codex generation:
```bash
cp .env.example .env.local
# edit .env.local and set your real key
# OPENAI_API_KEY=your-openai-api-key
# CODEX_MODEL=gpt-5.3-codex
# Optional for one-click GitHub PR from Codex editor:
# DEVSPACE_DEFAULT_GITHUB_TOKEN=your-github-token
# GITHUB_REPO_OWNER=your-org
# GITHUB_REPO_NAME=your-repo
# For honest demo behavior, keep this false:
# INCIDENT_AUTO_MERGE=false
```

3. Start the app:
```bash
npm run dev
```

If hot-reload gets unstable during demo (for example `Cannot find module './948.js'`), restart clean:
```bash
pkill -f "/Documents/ecom/node_modules/.bin/next dev" || true
rm -rf .next
npm run dev:clean
```
Keep only one `next dev` process for this repo.

4. Quick smoke test in browser (`http://localhost:3000`):
- Log in as `admin@devspace.demo` / `admin123` and confirm `/admin` loads.
- Log in as `jack@devspace.demo` / `demo123` and open `/profile/jack`.
- Open `Codex Editor` on your own profile and run one drastic prompt (for example `DRASTIC CHANGE: brutalist raw black and white`), then one very different prompt (for example `DRASTIC CHANGE: cosmic nebula galaxy`). Confirm the page changes dramatically between both prompts.

5. If Codex API is unavailable, demo still works with deterministic fallback themes:
- Cyberpunk, Y2K, dark-academia, minimal, vaporwave, cosmic, brutalist, and tropical fallbacks are built in.
- Call out that provider can switch to fallback, but the profile transformation remains dramatic.

## Part 1: The Platform (2.5 min)

### Open: Landing Page (30s)
- Show the stunning landing page
- "DevSpace is a developer social media platform where every profile is unique — generated by Codex AI"
- Point out the mini profile previews showing diverse styles

### Sign Up Flow (30s)
- Click "Sign Up"
- Enter a name, username, pick "Cyberpunk" vibe
- "When you sign up, Codex generates a completely custom profile page based on your vibe"
- Show the feed after signup

### Social Feed (30s)
- Scroll through posts from different developers
- Like a post, add a comment
- "This is a real social feed with posts, likes, comments — all persisted"

### Profile Takeover (60s) — THE WOW MOMENT
- Click on "Jack Chen" username
- The entire browser transforms into Jack's cyberpunk terminal aesthetic
- "Every developer's profile is completely different. Jack's looks like a hacker terminal..."
- Navigate to Mira's profile — soft pink minimal design
- Navigate to Zeph's — vaporwave retro
- Navigate to Nova's — cosmic starfield
- "All of this is generated by Codex based on text descriptions"

## Part 2: Codex Self-Healing (2.5 min)

### Show the Admin Dashboard (30s)
- Navigate to /admin
- "Behind the scenes, we monitor API health in one table."
- Point out all APIs are green except one intentionally degraded API row: `/api/internal/diagnostics` (isolated, not used by core user flows).

### Trigger Self-Healing (60s)
- Click `Fix in Codex` on the degraded row only
- "Codex creates the Jira incident, analyzes root cause, generates fix steps, and runs remediation."
- Click the generated `Open Jira Bug` link.
- Click the generated `Open Jira Board` link.
- Click the generated `PR` and `Codex Review` links.
- Walk through each timeline step as it completes:
  1. "Codex detects the anomaly from the Jira-linked incident"
  2. "Opens Jira and moves the issue workflow state to To Do"
  3. "Analyzes with the Responses API (Codex)"
  4. "Generates patch and opens PR"
  5. "Posts Codex review comment with @codex mention"
  6. "After merge, the API goes healthy"
- "If PR is not merged yet, dashboard stays degraded and shows pending merge"

### Wrap Up (30s)
- Show the metrics are green now
- "DevSpace shows two powerful Codex use cases: programmatic code generation for vibe-coded profiles, and autonomous incident triage + remediation PR generation"
- "All data persists in JSON storage, all Codex calls use the Responses API with deterministic fallbacks"
